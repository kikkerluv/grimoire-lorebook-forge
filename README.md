# Grimoire — Lorebook Forge (расширение для SillyTavern)

Генерирует записи лорбука (World Info) через ваш собственный API-ключ/эндпоинт
и отправляет их прямо в открытый в SillyTavern лорбук — без экспорта/импорта JSON.

## Установка

1. Найдите папку расширений вашей установки SillyTavern:
   `data/<ваш-хендл>/extensions/` (или `public/scripts/extensions/third-party/` в старых версиях).
2. Создайте там папку `grimoire-lorebook-forge` и положите в неё три файла:
   `manifest.json`, `index.js`, `style.css`.
3. Перезапустите SillyTavern (или обновите страницу, если сервер уже поддерживает горячую подгрузку).
4. Откройте вкладку **Extensions** (иконка вилки/розетки) — в правой колонке появится
   блок «🐸 Grimoire — Lorebook Forge».

## Использование

1. Разверните блок «🐸 Grimoire — Lorebook Forge», впишите формат/эндпоинт/ключ/модель.
   Кнопка «Сохранить подключение» неактивна, пока не заполнены все три поля.
   Это единственное, что живёт в самой панели Extensions.
2. Нажмите большую кнопку **«🐸 Открыть Grimoire — записи лорбука»** — откроется
   отдельное всплывающее окно (официальный `Popup` из SillyTavern). Всё остальное —
   выбор лорбука и работа с записями — происходит только внутри этого окна.
3. **Лорбук-получатель** (внутри попапа): выберите существующий из выпадающего
   списка (подтягивается через `getWorldInfoNames()`), впишите имя вручную,
   нажмите «Текущий чата» (подставит лорбук активного персонажа) или
   «+ Создать новый» — откроется системное окошко ввода имени и лорбук будет
   создан прямо в SillyTavern. Крестик `✕` очищает выбор.
4. «+ Добавить запись» — плодит сколько угодно карточек-черновиков, каждая со
   своим промтом, генерацией, названием/ключами/текстом и отдельной кнопкой
   «Отправить в лорбук».
5. Всё сохраняется в `extension_settings` — можно закрыть попап, закрыть вкладку,
   вернуться позже — черновики останутся на месте.

## О кнопке «+ Создать новый лорбук»

Создание идёт тем же путём, что и обычные записи — через `/createentry`, который
создаёт файл лорбука, если он ещё не существует, и сразу добавляет в него одну
служебную запись-заготовку (её можно удалить или отредактировать прямо в редакторе
World Info в SillyTavern). Отдельной команды «создать пустой лорбук» в STscript нет,
поэтому это самый надёжный способ гарантированно завести новый файл.

## Важно: места, которые может потребоваться поправить под вашу версию ST

Отправка в лорбук идёт через `context.executeSlashCommandsWithOptions(...)` —
это официальный, но иногда переименовываемый между версиями метод выполнения
слэш-команд. Если при нажатии «Отправить в лорбук» вы видите ошибку про
«не нашла метод выполнения слэш-команд» — откройте консоль браузера (F12),
наберите:

```js
SillyTavern.getContext()
```

и посмотрите, как называется актуальный метод для выполнения STscript в вашей
версии. Пришлите мне это имя — поправлю `runSlash()` в `index.js` за один шаг.

Выпадающий список лорбуков использует `getContext().getWorldInfoNames()` — эта
функция появилась в ST относительно недавно. Если у вас старая версия и функции
нет, список просто останется пустым («— выбрать из списка —»), но поле для
ручного ввода имени, кнопки «Текущий чата» и «+ Создать новый» продолжат
работать как обычно.

Всё остальное (генерация через ваш API, парсинг ответа, сборка команды) не
зависит от версии ST и не должно ломаться.
